# Planning archive

The `planning/` directory preserves the original materials previously stored in the root `requirements/` directory, including the supplied planning pack and duplicate templates. These are historical references, not current setup instructions or proof of completed work.

Use the root [README](../../README.md) for current application behaviour and deployment commands, the [documentation index](../README.md) for implementation details, and [submission/](../../submission/) for current submission files. Relative links inside historical documents are retained as originally authored and may refer to the original planning layout.
