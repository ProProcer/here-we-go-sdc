# Starter Template Handling

- This planning pack is adapted from the user-supplied SDC Hackathon GitHub starter ZIP.
- **Do not import or reuse the ZIP’s embedded `.git` history.** Create a new hackathon repository only after the official start.
- The original ZIP includes example `REPLIT PROOF OF USE.pdf` and `RUNPOD PROOF OF USE.pdf` placeholders, which were deliberately **not copied** into this planning pack. They are not actual evidence of the team’s usage.
- The included official blank PDF form is retained for completion; `docs/PRELIMINARY_PROPOSAL_DRAFT.md` is NOT a PDF submission.
- The supplied LICENSE is Apache 2.0, consistent with the Participant Handbook’s license instruction. Verify all future repository content has compatible rights.
- Replit is required; RunPod applies if a team workload requires a GPU.
